## 1. 三级角色及任课关联

固定应用角色为 `GLOBAL_ADMIN`（全局主管理员）、`TEACHER_ADMIN`（教师管理员）、`USER`（用户）。角色是管理权限，任教班级/科目/老师身份是业务关联，两者不能合成一个字段或由客户端自报。

- 首次使用创建全局主管理员，保留原口令、恢复码和最后管理员保护。全局主管理员可维护所有配置、资料、账号与任教关系，也可在自己的账号上关联任课科目/班级，作为实际任课老师被课表选择；关联任课身份不降低全局权限。
- 全局主管理员可为每个班级/科目指定默认任课老师，并在具体课表格或当前节临时换课中明确指定目标老师。同科目有多位老师时具体课表格优先，不能按最近上传、名字相同或随机顺序挑人。
- 教师管理员对应实际任课老师，至少关联一个班级和科目，可添加/删除自己授权范围的文件，维护本人作业及资料；Web可共同维护同安装学校全部当天提醒，并可向本人任教且本白板绑定班级发起语音播报，不能改组件/布局/换课。
- 用户默认只查看展示及打开当前课堂已发布资料，不允许添加、删除、改布局、改课表、改提醒或换课。用户账号不要求任教科目；全局主管理员可限定其班级范围。
- 默认桌面未登录访客使用“当前课堂只读用户”上下文，仅允许主动点击当前已发布文件。没有教师后台权限，不把访客当主管理员或教师。用户登录后也不能读未发布/其他班级原文件。

| 能力 | 全局主管理员 | 教师管理员 | 用户/桌面只读访客 |
| --- | --- | --- | --- |
| 账号/科目/任教/课表/校历、所有组件和布局 | 全部 | 拒绝 | 拒绝 |
| 本人资料/作业内容 | 全部 | 仅本人且有效任教范围 | 拒绝写入 |
| 今日提醒写入 | 仅Web，全部受管班级 | 仅Web，全部受管班级/任何作者 | 拒绝 |
| 当前节换课/恢复原课 | 仅全局本地 | 拒绝 | 拒绝 |
| 查看/本地打开当前已发布文件 | 允许 | 允许；工作台可备课开本人文件 | 当前课堂只读 |

## 2. 教师资料文件夹与存储

每位任课老师有稳定teacherId，在ProgramData内拥有系统管理的资料目录，按科目分子目录：

```text
%ProgramData%\FutureClassroom\
  state\classroom.db
  resources\teachers\<teacherId>\subjects\<subjectId>\<materialId>\<version>.<ext>
  launches\<launchId>\<safeDisplayName>.<ext>
  staging\
  backups\
  logs\
  runtime\
```

teacherId/subjectId/materialId来自已校验内部对象，不接受网页提交本机绝对路径、UNC、URL、快捷方式目标或目录命令。逻辑界面显示“陈老师 / 英语”等名称，目录键不使用可重名的教师中文名。同一老师的不同科目相互隔离；一门科目多位老师各有目录。班级可见范围由资料allowedClassIds和任教关系控制；同一物理目录不代表全部班级可读全部文件。

主管理员与教师在Web/本地工作台通过“添加文件”导入或上传，程序将副本存入受控目录并提交索引，不直接引用教师U盘或外部路径。课堂资料默认**不生成、不下载也不加载缩略图或人工封面**。原独立图片磁贴仍可有显示尺寸缓存，不把取消课堂缩略图误解为取消全部图片能力。

现有原件迁移为按teacherId/subjectId组织的受控目录；迁移清单与资源引用验证完成后才切换权威位置，失败回到源，不双写。不需要的旧缩略图在确认无独立图片/备份引用后有界回收。配置、布局、任教关系与资料索引仍由SQLite单写者事务管理。

## 3. 资料索引、倒序与增删

| 对象 | 字段/规则 |
| --- | --- |
| TeacherMaterialFolder | folderId、teacherId、subjectId、revision；目录ID不可由用户任意改成路径 |
| MaterialRecord | materialId、folderId、displayName、resourceVersionId、allowedClassIds、addedAt、addedSequence、status、revision |
| MaterialListSnapshot | classId、sceneGeneration、teacherId、subjectId、folderId、folderRevision、有界文件名/ID列表 |
| OpenMaterialRequest | 本地来源、可信actor、context(CURRENT_SCENE/OWNER_WORKBENCH)、materialId、resourceVersionId、sceneGeneration或工作台目录上下文、requestId；不含可执行命令/路径 |
| LaunchLease | launchId、资源固定版本、受控副本路径、创建时间、资源计账/清理状态 |

排序固定为 `addedSequence DESC`，addedSequence由本机Writer在成功加入资料目录的提交点分配，展示的addedAt也取本机提交时间。这样语义为“本系统最新加入的在最上”，不依据原文件mtime、教师电脑时间、文件名或最后打开时间。墙上时间回拨不颠倒顺序；打开、下载和重命名不刷新加入序号。无需为排序每秒扫描文件系统。

批量导入先校验清单及文件，按已确认清单顺序分配序号；UI明确本批最新项，提交前失败不显示半成品。相同文件名再次添加默认新条目，不静默替换；若后续提供明确“替换”，作为新版本/新加入操作并按新序号上移。显示重名文件时管理页可用加入时间辨认，普通桌面仍只显示文件名。

添加/删除校验角色、老师/科目/班级范围、目录有效性和目标文件引用。独立追加不因其他新增推进folderRevision而拒绝或取代旧任务；删除核对稳定materialId及其expectedMaterialRevision，立即从有效列表移除并推进目录修订，不能按可见行号删除。目录修订用于列表游标和快照一致性。物理回收等所有有效引用及打开租约释放；不可因一个老师删除文件损坏其他引用。账号停用、任教撤销、换课及上传并发仍在统一裁决域复核权限与上下文。

桌面只加载当前目录前若干项，初始5条，更多用有界分页/展开列表；不一次读完整文件或全校资料库。管理页初始每页20项，游标绑定目录修订，刷新/翻页不混合两个老师列表。长文件名换行/省略时保留扩展名并可查看完整名称，命中区域与绘制行一一对应。

## 4. 课表及临时换课到老师文件夹

```text
实际日期/校历/单双周 → 已有有效课时
→ BREAK：公共视觉+上一课最终有效老师目录（RETAINED_BREAK）
→ 其他非COURSE：公共午休/活动/空闲布局，不读个人目录
→ COURSE：课表subjectId + teacherId（或明确的该班默认老师）
→ 当前节覆盖存在则取目标subjectId + targetTeacherId
→ 检查任教关系 → 取相应folderId及倒序资料索引 + 科目profile
→ 合成共享磁贴 → 原子发布SceneSnapshot
```

默认老师仅在课表格明确使用“科目默认老师”模式时适用；显式老师失效不得悄悄改成默认老师。临时换课列表选择目标科目及老师，立即切换目标老师该科目的目录、布局与设置。菜单和文件点击都携带场景代次，旧数学行在英语课到点后不能继续当作当前英语资料打开。

未分配老师、停用、目录无文件时显示中性“该老师暂无课堂资料”等空状态，不借用上一科或另一位老师目录。课间仅保留上一课最终有效老师资料，午休按既有规则；临时换课只影响当前节，但其实际老师目录会保留到随后课间，下一节恢复基础课表；普通用户没有换课写权限。

## 5. 文件名点击、本地打开与避让

文件名行是明确的小范围交互区；只有可点击行、“更多资料”和已授权按钮接收鼠标/触摸，磁贴空隙、背景、作业/课表正文继续穿透。文件一经打开导致外部应用前台，整个展示、行命中区、菜单均隐藏；返回桌面重新读取当前课、目录和提醒后恢复。它不是置顶文件启动器。

打开流程：本地用户主动点击 → 命中materialId及固定resourceVersion → 校验当前场景/班级发布可见性/文件类型 → 受限Worker流式准备受控打开副本 → 回调复核账号/场景/资料状态 → 专用有界STA启动执行器调用系统 `ShellExecuteExW` 的 `open` → 返回启动请求结果，VisibilityPolicy独立处理前台。

上述为桌面CURRENT_SCENE模式。教师管理员在本地工作台可主动打开本人任教范围资料，全局主管理员可打开任意受管资料，使用OWNER_WORKBENCH模式复核登录会话、目录和资料版本，不要求文件恰好属于当前课，以便备课。该模式由可信本地控制器生成，普通用户、网页不能自报模式获得权限。桌面模式在切课时取消旧请求；工作台模式不因切课取消已明确的备课选择，但仍受撤权/退出/删除检查。

只传系统控制的绝对文件路径；不拼接shell命令，不经cmd/PowerShell、不提权、不传教师自定义参数。COM/STA和启动错误处理按[微软ShellExecuteExW说明](https://learn.microsoft.com/en-us/windows/win32/api/shellapi/nf-shellapi-shellexecuteexw)；文件open动作依赖已安装文件关联，见[微软打开应用说明](https://learn.microsoft.com/en-us/windows/win32/shell/launch)。Win7上对应软件与文件格式兼容性必须实测。系统Shell打开是用户主动行为，与后台不自动调用Office渲染资料是两种不同用途。

PPTX由电脑已有PPT/WPS等关联程序打开，PDF由现有阅读器打开；软件没安装/无关联给出“未找到可打开此文件的程序”，不自动安装软件。文件缺失、权限变化、用户取消、关联失效和副本配额不足分别提示。文件打开不承诺自动进入放映，也不承诺打开某一页。

首次允许的资料白名单沿用PNG/JPEG/BMP/TXT/PDF/PPTX/DOCX/XLSX，文件头/容器检查继续保留；可执行、脚本、快捷方式、宏/加密等拒绝规则不因“能打开”而取消。旧PPT/DOC/XLS是否增加支持需单独验证，不能从扩展名推断无宏。

打开副本保留安全文件名、固定资源版本，外部软件保存不直接改动已发布原件；教师需要更新时重新添加/明确替换。这样打开期间删除/更新源条目不会破坏正在授课的文件。准备期发生删除、换课或权限撤销则取消启动；启动之后不强行关闭PPT。对已打开外部软件的文件访问不能用应用内账号实时收回，不能假称具备这种能力。

`ShellExecuteExW`成功只说明启动请求被系统接受，不代表文件已渲染或PPT正在放映；返回 `LAUNCH_REQUESTED / LAUNCH_FAILED / ASSOCIATION_MISSING / CONTEXT_CHANGED / USER_CANCELLED` 等动作结果，不复用“内容COMMITTED=已打开”。不等待外部程序退出，不可靠依赖一个进程句柄判断关闭（可能复用已有应用）。启动动作不在崩溃恢复或请求超时后自动重放，同requestId短时去重，避免反复弹PPT。打开副本单独计账，初始上限200MiB/准备并发1、排队有界，连续点击短时去重。副本清理由文件占用/租约和宽限期判定，锁定文件不强删，不足拒绝新启动并提供管理清理；详细上限在P0/P5按真机校准。

Web只上传/管理/下载文件，首版**没有远程启动白板软件接口**；点击Web下载文件是在教师自己的设备处理，不假装白板已打开。

## 6. 新布局与既有功能

依据用户新参考：左侧约54%保留干净桌面，右侧约44%为信息区，余量作边距。右侧按作业、课堂文件名、时钟/课表分列，下方整齐放日期倒计时与当日提醒。比例为本轮视觉建议，可自适应屏幕；不把所有磁贴做成铺满屏幕的交互窗口。
