# 跨安装显式映射恢复

总计划 1.38 / D11，2026-10-31。对应 P2-05、M02/M03/M06 与 Q02/Q04/Q11/Q25。本文记录第二十五轮新增实现的契约；构建、Host 测试、Windows 运行、失败与清理结果由[实施记录](10-实施进度与验证记录.md)分别登记，本文不预称通过，也不将 P2-05 或完整产品标为完成。

## 独立入口与授权范围

普通备份仍采用[完整普通备份契约](23-完整备份与受控恢复.md)规定的无凭据投影、完整包校验与安装绑定。普通恢复入口继续拒绝其他安装的包；不能以学校、班级或账号数字 ID 相同来绕过。跨安装操作由本机主管理员进入专门的显式映射向导，使用同一完整包格式，先校验来源，再由当前目标安装的唯一 writer 生成新的普通教学投影。

源包只提供教学事实与非授权显示标签，不提供登录名、密码验证值、恢复码、DPAPI 密钥、角色、停用状态或任教授权。映射到目标账号不授予任何额外角色或范围，也不导入源账号凭据。缺少目标班级、科目或账号时，取消本次来源，通过已有本地管理流程建立目录与账号、发放新的初始口令并配置任教权限，再重新选择包；向导不临时创建身份或静默补授权。

首次尚未建立目标学校和主管理员的部署，先完成正常初始化；无恢复码时放弃当前部署属于[独立重新初始化](24-无恢复码重新初始化.md)，不与本入口合并。

## 全量显式映射

源目录 `MigrationCatalog` 包含学校、当前班级、全部班级/科目/账号显示标签及默认教师。上限为班级 128、科目 256、账号标签 512。来源的历史作者、所有者或其他身份引用必须能在受验证目录中解释；未知引用拒绝，不能猜测为某个同名账号。

| 类别 | 显式选择要求 | 目标侧约束 |
| --- | --- | --- |
| 学校 | 来源学校绑定当前目标学校 | 保留目标学校身份、名称及安装标识 |
| 班级 | 每个源班级选择一个实际存在的目标班级 | 同一目标班级只能使用一次；映射后的当前班级须启用 |
| 科目 | 每个源科目选择一个实际存在的目标科目 | 同一目标科目只能使用一次；保留目标名称与颜色 |
| 账号标签 | 每个源账号标签选择一个实际存在的目标账号 | 同一目标账号只能使用一次；保留目标登录名、显示名与当前安全属性 |

各类型映射必须覆盖全部源对象，并分别满足目标不重复的一一映射；不同类型的数字 ID 不构成同一命名空间。不按同号、同名、当前默认教师或列表顺序自动选择。未选择、漏项、重复目标、未知目标及目标学校不符都阻止预检，不能跳过对应教学对象后继续。

历史引用可映射到仍实际存在的停用目标，但当前班级、默认教师和课表等活动关系须满足当前启用状态与真实任教权限。最终 writer 对全部强类型教学关系再验证，历史映射不是使用当前教学功能的授权。

## 原生向导与确认边界

向导先展示来源学校、安装与修订、当前目标及修订和所选完整位置，再按班级、科目、账号分页，每页最多五个源行。每行显示来源及当前所选目标的完整信息；所有选择默认未选，保存及上一页/下一页只改变草稿，不提交正式教学资料。长位置分页完整显示；状态与标签拒绝控制字符并遵守原生 UTF-16 预算。

页面保持最多 16 个字段、12 个动作、每个 Choice 最多 1024 项的现有原生预算。页选择值绑定当前所有者、检查序号、页代次、类别和源对象；默认未选值同样绑定当前页。陈旧页面、缺失/重复/未知字段、错误类型与伪造选项均拒绝，整页验证成功后才原子保存。表单不能提供文件路径、清单、凭据或恢复能力。

完整映射提交只请求预检，并递增草稿修订，不授权恢复。预检成功后展示教学替换及目标安全资料保留的完整影响，要求两项默认未确认的明确选择：确认完整教学替换，以及确认保留目标身份/授权、关闭程序并重新登录。内部确认值绑定本次检查序号和草稿/页面代次；旧页已选择值、只有一项确认或默认值都不能触发恢复。确认只消费一次；锁定、取消或检查失效后不能复活。

后台忙时仅允许取消及外层锁定；取消或目标管理离开向导会失去本次源能力。映射预检已消费来源后发生失败，同样须重新选择外部包，不能回到看似可重试、实际上已失去物理来源的旧草稿。已保存的外部包不会因取消而被删除。

## 教学整体替换与目标保留

| 恢复后的范围 | 处理规则 |
| --- | --- |
| 当前目标目录与安全资料 | 保留目标学校/安装、全部班级/科目/账号、名称/颜色/显示标签、登录名、密码和恢复码、角色、停用与任教权限、登录限速及当前系统事实 |
| 来源教学事实 | 当前班级、默认教师及全部教学文档依显式映射重写；课表/双表/校历、作业/提醒、布局、当前与上一版内容、资料与图片按完整包整体替换 |
| 未被源映射使用的目标对象 | 目录和账号仍保留，但其旧教学资料也属于整体替换范围，不以“未映射”为由留下旧教学内容 |
| 旧运行权限及系统动作 | 不恢复旧会话、配对、语音原件/队列，不重放旧系统操作或自动开启网络/自启动；确认后旧本地/Web/场景能力失效 |

这里与普通同安装恢复的源显示标签恢复规则不同：跨安装路径始终保留当前目标的目录和账号标签。保留密码与任教范围不表示保留旧会话；确认屏障仍递增当前授权及恢复代次，之后重新启动并使用当前目标凭据登录。

## 精确修订、类型重写与物理所有权

来源检查把完整包清单、实际普通数据库字节/SHA、来源安装/学校/修订以及当时目标身份快照与全局修订 R 绑定在不可伪造能力中。目标在此后发生任何全局修订变化，都须重新选择并预检。不能取得新 R 的访问能力为旧目录、旧映射或旧预检重新背书。

主泵只以非阻塞方式读取内存中已发布的全局修订，观察到漂移即取消并使向导失效，不在 UI 线程等待数据库查询。暂未取得读锁不表示校验通过；writer 在检查、映射、预检和确认边界仍核对精确 R、当前会话及能力。

唯一 writer 按 schema 和强类型 ID 重写学校、班级、科目、作者/所有者及相关教学引用，以当前目标目录生成全新普通数据库投影，并重算包含这些引用的图指纹。源数据库不原地修改；映射后的清单使用当前目标安装标识，不透明结果能力另行绑定来源摘要及规范映射摘要。随后复用普通同安装完整预检，构造绑定当前目标与实际映射产物的隔离 preview；不能只替换清单安装号，也不能对任意 JSON 字符串作同号替换。

同一恢复工作流只保留一个源/预检槽。完整包读取时固定所选文件；全部解帧、摘要、真实格式与引用检查完成后，槽持有保护工作区、普通数据库和媒体/祖先目录 pin，原始外部包句柄才可释放。轻量 UI 对象仅引用对应代次，不能用路径重新打开来代替物理所有权。

取消、锁定、迟到结果和最后 UI 句柄释放只请求回收。重型工作区析构在现有 worker 上执行，真实完成前不复用槽；映射预检消费来源后，失败在该 worker 上回收来源与新工作区。UI 不递归删除大树，不新增常驻文件 worker，也不因 JobTicket 已取消而声称句柄与工作线程已退出。

## 明确确认后的真实关闭与重开

双确认成功后复用普通恢复的耐久授权屏障、不透明 ReviewBundle 和独立最终协调器。先持久撤销旧能力并进入不可逆接纳状态，再停止并实际回收 Shell、共享 worker、音频等所有权；唯一 writer 从最新当前安全事实构造最终候选，实际关闭并 join 后才取得冷切换许可。

文件服务核对实际候选及来源事实后，按恢复日志切换 `state`、`teachers`、`profile-content` 三树，保留目标根目录、现有密钥和实例锁。多个目录 rename 不构成原子事务；中断按普通启动核对契约处理，歧义保留证据进入修复。确认后只能安全中止或退出，不能恢复普通工作台接纳；逻辑完成和线程结果消息均不能代替实际 OS 线程退出及 join。完成页明确关闭后，释放原实例才能由独立进程重新打开同一目标部署。

## 验证范围与仍待取证

纯规则及 writer 回归应覆盖映射完整性、逐类型目标唯一、同号/同名不自动匹配、未知引用、目标安全属性保留、全类型重写/图指纹、输入完整包与媒体绑定，以及目标 R 漂移不能重新背书。原生编辑器回归覆盖默认未选、陈旧页、重复字段、局部确认、锁定、失效及取消，不把模拟表单等同于可见设备操作。

`scripts/windows-probe.py --migration` 使用独立 `--migration-probe`，约定 16 个有序步骤、独立可执行文件重开标记及最终范围报告。诊断应建立隔离合成的来源/目标，验证普通入口拒绝异安装、取消真实回收、不完整映射拒绝、预检不改 live、双确认接管、真实关闭与三树切换、当前目标凭据登录及映射内容、源包和目标密钥未变，最后清理自有部署。主脚本只读核对真实 HKCU Run 项，不能为诊断改变用户自启动；选择器测试只注入隔离能力，不冒充实际可见原生对话框。

步骤及输出校验器已经定义，不代表本次诊断已执行或通过；实际日志与清理结论由实施记录登记。Windows 7 SP1 x86、Windows 10、Windows 11 均须独立保留证据；同机 GNU 补充运行、Host 测试、静态 PE 检查及隐藏原生探针不替代真实三系统、MSVC、希沃前台/触控/教学软件、掉电及完整发布验收。
