### 配对秘密与本地审批

`fc-security::web`新增256-bit WebSecret、带固定域分隔的SHA-256验证摘要、固定长度恒时验证、八位十进制PairingCode和显式出站SecretText。随机生成有界拒绝全零/不适用样本；解析消耗并清零输入，秘密不提供普通Clone/Display/序列化，诊断只显示REDACTED。只有明确的配对响应、CSRF响应和Set-Cookie边界借用出站文本，不将凭据放URL或日志。

`Backend::web_service()`提供进程内Web准入服务，默认关闭；启用此逻辑服务不创建HTTP监听、证书绑定或URLACL。本地精确、未过期的GlobalAdmin Manage lease才能开启120秒配对窗口、查看已有账号/设备名/任教范围、按身份修订批准或拒绝申请。八位码只创建PENDING申请，并在第一次匹配时消费，不能凭短码自动授予角色；无效账号也不能复用同码枚举。120秒内最多10次短码尝试，限额不因新窗口重置；最多8条申请、64台设备，轮询至少间隔500ms。

原申请者持有独立256-bit pollSecret才能领取已批准结果；服务仅保存该秘密和Cookie的验证摘要，CSRF保留在受清零秘密类型中。批准捕获现有账号、权限范围和当前班级，领取时重查；身份/班级改变、local代次失效、窗口过期或时钟倒退均不能继续领取。关闭配对/应用重启不恢复待批准申请或秘密。本地锁定只撤本地会话及其待完成审批，不撤已经建立的独立Web设备会话；禁用Web服务则撤销所有Web准入。

`IdentitySessions::issue_approved_web`在同一本地账本重查精确审批lease、Local/GlobalAdmin、安装学校、目标enabled及已完成首次改密，追加独立Web lease，不替换同账号其他已批准设备。单设备撤销只删除原精确proof，过期/撤权记录可回收；原密码登录`issue_verified`仍保留同账号同origin替换语义。单调期限与墙钟期限分别生效，duration和sequence均不wrap；本轮Web设备以签发后8小时与当日午夜二者先到为期限，不保证跨日持续8小时，进程重启不恢复。不能据此宣称完成持久长期配对凭据的备份/恢复方案。

### 显式账号注销与应用端口

### 行为、权限与不确定结果

录音目标仅白板当前实际绑定班级；教师须该班有效任教，主管理员也不能任意投向其他未绑定班级。语音不沿用共同提醒宽范围。查询/停止沿本人或全局有权任务，换班/关闭功能/停止接纳后仍能查停旧任务。合法配对的普通用户读语音能力与列表也返回403，不能通过新增只读入口绕过角色门禁。

录音开始固定原班级、身份修订、运行代次和总次数，录完上传前再读能力，变化即取消，不替换目标或补发。默认总3遍包含首次，可选1–10遍，遍间静音1秒。按住/正常松手发送，上滑取消，空格/Enter、Esc及点击开始/结束替代均可用；权限迟到、pointercancel、隐藏/失焦/离页、音轨/上下文中断均取消未发送内容，迟到track立即stop。达到60秒按当时手势finalize一次，随后松手不能重复发送。

实际采样率的AudioWorklet显式多声道均值mono，OfflineAudioContext重采样16000Hz，独立Worker输出PCM16LE/单声道/固定44字节头WAV，0.5–60秒/8000–960000帧；没有MediaRecorder容器猜测、云端转码、新npm依赖或真实白板麦克风采集。每份上传最长600秒，16MiB正文与预留共同计费、4任务/每教师2、未提交全局2/每教师2、32物理资产等既有门槛继续生效。

提交后原jobId等于原commandId，重复同负载读取现有任务当前状态，不创建第二次播报。503/网络未知只手动GET原jobId，404不证明从未提交；停止也不自动重发。STOPPING等待实际驱动归还，不能显示已停止。驱动COMPLETED不保证扬声器开启或人耳听到。设备能力目前诚实为UNVERIFIED，实际执行时由现有WAVE_FORMAT_QUERY检查；session/admission可用不是扬声器保证，可信设备能力缓存仍待后续集成。

### 已实现的测量修复

原场景层将课表、作业或资料拼成最多16KiB估算文字，并按外宽减32 DIP测量；原生绘制却使用外宽减48 DIP、作业标题与正文两个块、独立胶囊/操作高度和资料行距。这种不一致会使内容在能够容纳时提前分页，也会使增大资料行距后父容器或画布矩形没有相应增高。

现在纯CardBodySpec保留完整块文字、对齐/填充、实际数据叶和MaterialRow/MaterialMore角色；场景、布局求解和原生DirectWrite准备使用同一分块与几何。静态正文左右各24 DIP、块内上下各8 DIP；高度为真实文字测量加上下留白并满足普通24/填充与操作44 DIP最小值，间距只加在相邻块之间。资料使用profile捕获的0至64 DIP间距，末块保留完整留白，不再由原生另减8 DIP。普通标题32 DIP、未核验课表50 DIP、底部12 DIP，资料回退说明也同时计入测量与绘制。原生根据显式动作角色映射稳定文件ID和固定版本，不再按块偏移猜条目。

WidgetMeasure改为承载共享body，去掉16KiB截断样本；数字钟、模拟钟、课间和换课控制条采用各自明确动态规则，秒钟仍只刷新原小区域。完整文字、128课程/64作业/5资料/128块、每卡262144 UTF16单位、64可见叶和16MiB应用DIB边界保持。文字分页继续16384页；原计划50页属于分页图片文档，本轮不实现图片文档，也不将其误套合法长文字。

现代 GNU x86 与补充 Win7 GNU x86 **均在同一 Win11 Pro build26300/WOW64** 上完成两批八连接：4次通过真实证书和 localhost 校验的 TLS1.2 握手、2个分片加密 HTTP 响应、3次原批次截止关闭，以及错误 CA、错误主机名的实际拒绝（SSLCertVerificationError 18/62）。协商 ECDHE-RSA-AES256-GCM-SHA384、256bit；每个客户端检查服务端公共 DER 的精确 SHA。两种程序各有 IOCP45/45、SSPI25/25、Frame归还25、排空时8份槽 Frame；实际遇到2次 EXTRA 共62字节。错误证书测试产生的2次原生握手错误保留在报告中。见[现代实际TLS](验证记录/2026-10-31-round26-modern-tls-stage5.json)、[补充程序在同一Win11的实际TLS](验证记录/2026-10-31-round26-win7-tls-on-win11-final.json)。两者的真实慢 SSPI 在途关闭计数均为0，不据此声称已经中断了系统加密。

关闭顺序另由 Windows 真实 socket/IOCP 加持有的**假 Driver**覆盖：关闭时仍持有1份物理 Frame，释放假 Driver 后才收齐晚到结果、检查释放、观察实际线程退出并重开新 generation；实际 IOCP5/5、晚到结果1。独立子进程实际等待五秒排空超时，保持 RETAINED_FAULTED、cleanupComplete=false 和禁止替代；最后进程退出回收，不能冒充正常 Closed。另测 Windows 线程 TLS 析构仍阻塞时 Rust finished 不足以回收。该组证明生命周期顺序，不证明真实 OS 加密可中断。
