## 1. 实现顺序与边界

先纯领域模型/校验，再原生表格和时间掩码，再双表，再双模式校历，最后接高亮/倒计时。公共资料下载不阻塞学校模式；无学校校历不阻塞普通课表。教师Web首版无课表写接口，不为复用视图引入白板WebView。

## 2. P4-01：学期和作息模型

1. 定义Semester、WeekTable、TimetableRow、CourseCell、TimeRange、TeachingWeekAnchor和值对象错误。
2. 学期起止日期必填、顺序有效；启用学期不可重叠，明确一个当前学期，学期外显示未开始/结束而不是全年循环。
3. 第一教学周锚点为周一，可早于实际周二开学日；默认建议开学当周周一，老师确认，不直接使用ISO周号奇偶。
4. 教学周公式为基于锚点的完整7日差+1，学期外先过滤；明确修正只按经确认的校历设置，不因假期数量自动扣周。
5. 作息行含稳定ID、逻辑行键、上午/下午等分组、类型COURSE/REST/ACTIVITY、名称、范围及适用星期。
6. 课程格从主管理员建立的学校科目表选择subjectId，任课老师按该班该科目候选关联；唯一候选自动选，多名必须指定，暂无老师须明确标记未分配并提示默认布局。教室/备注可选，空格表示无课；活动行与课程科目分开。
7. 各生效星期的全部启用行时间有序不重叠；跨午夜/24:00不支持，输入精度为分钟；学期修订一次覆盖所有启用表。

## 3. P4-02：原生网格和时间控件

1. 管理员打开页时加载修订为草稿，上方填学期/班级/锚点，下方为星期列、时段/节次/时间列。
2. 按参考图绘制上午/下午分区、星期一至五及可选周末、跨星期活动行；用当前格临时编辑控件，不给全网格永久建输入框。
3. TimeRangeInput持有8个数字位，固定显示 `XX：XX-XX：XX`；输入 `08200900` 得 `08：20-09：00`，自动跳过标点。
4. 实现光标左右、分段选择覆盖、Backspace/Delete、粘贴8位数字和全角数字归一；不要用普通文本框的任意字符串代替数字位模型。
5. 草稿允许不完整；保存时00–23小时、00–59分钟、起<止、无重叠全部检查，错误返回页/表/星期/行/格。
6. 增删/移动行、复制到其他星期、活动行拆合都更新逻辑键；移动只改排列不悄悄交换课程内容。名称“课间”不自动决定行类型，须选择REST及用途；只有符合第9节条件的RECESS启动课间大字显示。
7. 局部预览与取消不写修订；保存前重查会话和expectedRevision，过期可重新解锁后继续草稿。

课程格编辑器为科目下拉选择，不接受任意科目文字；“管理基础科目”仅主管理员入口，原有数字时间控件、作息/单双周/校历算法保持不变。稳定subjectId重命名不破坏引用，停用/删除先检查课表、任教、profile、临时覆盖等影响。

P4-08在已有课时解析后调用M16，依据subjectId+teacherId取个人profile；P4-09提供当前节临时覆盖。休息/午休不选择任何个人视觉profile；课间资料单独保留上一课实际目录，下一节按课表切换资料。切换目标科目不修改行时间和公共倒计时，课表/校历变更使旧当前节上下文失效。完整边界见[多科目手册](07-多科目联动与临时课堂.md)。

## 4. P4-03：单双周向导

1. 基础表填完并通过校验后选择是否单双周；关闭时使用统一表。
2. 开启在草稿中深复制A/B，所有课程/备注/活动/时间相同，但对象和tableId/rowId独立。
3. 逻辑行键用于明确同步作息，课程格不会因改A而改B；两表分别编辑并保存各自差异。
4. 单周odd、双周even角色各一张；重复或遗漏拒绝保存。交换角色不改变内容和时间。
5. 作息同步默认开启，明确作用范围是时间/作息结构而非课程；目标行不存在、结构不匹配或同步后重叠，整次操作返回错误并让老师处理。
6. 已生成的表重新打开不再复制；关闭单双周要求选择保留表，另一表留在有界历史中；再开明确恢复历史双表或重新生成，不能静默覆盖。
7. 统一表/双表切换、两表内容和角色在一个学期修订提交。当前授课状态选中实际表后再计算该表作息。

## 5. P4-04：两种校历模式

配置：`useSchoolCalendar=false`默认；学校/公共的候选、已采用数据、映射和来源各自隔离。每项临时覆盖也带模式归属；跨模式复制必须管理员主动确认。

| 情况 | 解析结果 |
| --- | --- |
| 学校模式，有有效覆盖且当天有明确特殊安排 | 按学校假期/补课/活动与周次修正 |
| 学校模式，有效覆盖内无特殊日 | 常规周课表，不能误判未录入 |
| 学校模式无配置/损坏/当天超覆盖 | UNCONFIRMED；暂停相关高亮/休息计时，时钟正常，不回退公共日历 |
| 公共模式，已采用休息日 | REST，课程不运行 |
| 公共模式，已知补班但未确认课程映射 | UNCONFIRMED，不猜周一或单双表 |
| 公共模式资料下载失败，有已采用缓存 | 按缓存，显示最近成功时间 |
| 公共模式某年度资料未知，普通日期 | 普通表可用并标“调休资料未核验”，不把未知标成官方确认；明确补班异常日按上一条处理 |
| 任何模式，当前日期在学期外 | OUT_OF_TERM，普通时钟/内容继续，无跨夜课间计时 |

实现步骤：定义模式值对象→校历范围校验→独立保存两个数据集→日期映射编辑→纯解析器→切换预览→事务提交模式和有效版本→立即重算今日。

补课映射优先选择具体来源日期；来源必须属于可解析学期，直接取基础星期/该周角色/课程，不递归执行其日期覆盖，禁止环和自指。若学校指定“按周一”，老师还要明确单/双或具体教学周。截止时间以实际补课当天构造，不能把来源日期的历史时间拿来倒数。

## 6. P4-05：公共候选资料

1. CalendarProvider抽象出获取和验证，官方通知作为依据，开源资料只是可替换候选源；版本/许可证/来源留痕。
2. 限制拉取频率、字节、日期条数和重试；学期跨年检查相关年份，可能影响上一年末的条目按来源归并，冲突待确认。
3. 解析年份、来源通知、日期、休息/补班标志；空数组或空来源不是“当年无假日”的证明。
4. 候选单独保存不生效，设置页展示差异、覆盖范围、拉取时间、来源和错误；老师确认后写采用版本与教学映射。
5. 纯放假变化自动采用开关默认关闭；启用也不能改学校模式或覆盖老师已确认安排，受控来源校验失败拒绝自动采用。
6. 模式切换后正在下载的结果只落候选缓存；学校模式默认不需要拉取公共资料来运行。

学校校历来源初期为管理员在日历界面对照学校文件维护，并不承诺任意校历图片/网址自动识别；学校有稳定接口时另实现提供器。

## 7. P4-06：课时、高亮和倒计时

1. 取同一修订快照，先日期/模式/教学周/表角色，后有效作息和课程格。
2. 区间 `[开始,结束)`；09:00既是上课结束又是课间开始时，只保留休息状态。
3. COURSE且格非空才高亮课程；空格无课，ACTIVITY显示活动，REST按用途和第9节判定是否显示课间剩余。
4. 明确休息行到其结束截止，即使后面是眼保健操也不谎称下一节上课。
5. 自动空档仅在同一分组相邻有效课程之间，剔除被ACTIVITY/REST占用的时间；不跨午休、夜晚或假日。默认采用总计划的同上午/下午范围。
6. 剩余秒数由实际目标时间减当前系统时间向上取整；超过1小时显示HH：MM：SS，不溢出为分钟回绕。
7. 只在可见且需秒显示时请求1Hz；业务边界另有一次性预约。系统改时/唤醒/模式或表修订变化立即重算，generation不符丢弃旧任务。

## 9. 剩余桌面课间大字倒计时：自动出现与关闭

此节细化既有R04/P4-06，优先于前文泛称“REST显示剩余”。沿用同一课表解析器，不增加独立一套下课定时器。

### 9.1 可显示状态与边界

- `RecessDisplaySettings.enabled`默认true；只有全局可改。状态分为INACTIVE/ACTIVE/SUPPRESSED：INACTIVE无有效课间；ACTIVE为有效课间且桌面允许展示；SUPPRESSED为有效课间但应用前台/锁屏等禁止展示。SUPPRESSED不绘制/不留输入区，回桌面必须先重算再恢复。
- 显式REST增加`restPurpose=RECESS/LUNCH/OTHER/UNKNOWN`；新建课间行为RECESS，午休为LUNCH。名称只是标签，不用名字猜用途。旧REST若没有可靠用途字段保留原行并标UNKNOWN，提示全局在作息设置确认，确认前不把它作为自动弹出的课间大卡；旧课表时间和正文不丢失。
- 有效课间为：当天已解析且同一上午/下午分区已有有效课程下课后的RECESS行；或已启用自动空档、同分区相邻有效课程之间且未被其他作息占用的空档。不跨LUNCH/分组/活动/夜晚推断空档；无后续有效课程的放学空档不计时。REST行之后没有同分区后续课程时也不生成课间大卡。
- 目标时间为当前RECESS行结束或有效空档后的课程开始；若随后是活动，只写“距本次休息结束”，不写“距下节上课”。活动期间隐藏；下一有效课间重新判定。
- 所有区间为[begin,end)。进入COURSE、LUNCH、ACTIVITY、IDLE、OUT_OF_TERM或UNCONFIRMED时同步清空倒计时卡、间距与命中区；绘制前若now已达deadline，先重算状态，不能把旧tick的00:00挂到上课中。
- 启动/唤醒/回桌面在课间即直接计算剩余时间，不依赖曾接收“下课”通知。系统改时、课表/校历修订和换班重算；旧generation不能恢复过期大卡。临时换课仅影响课程身份，不改时间，不能触发倒计时重置或在休息中强行换课。

### 9.2 视觉、布局和刷新

用户已更正：大卡不再放在右边，而是占满右边现有作业/课表/课堂资料等之外的主要可用桌面，默认为左侧大块区域。先对选定屏幕工作区（排除任务栏）完成右侧常驻磁贴布局，扣除其Rect保护区和间距，再取主要连续可用区域作为大卡边界。右侧不留原计时卡空位，其他卡片自动补满；避免按多屏虚拟总宽分半，也不把大卡覆盖到右侧内容上。

数字等宽粗体，按可用区域宽高及MM：SS/HH：MM：SS位数尽可能放大，1080p参考约220–300DIP；标题/下一课/单位明显小于数字。小屏/high DPI按实际DIP与字体测量适配，不裁剪、不越任务栏。背景玻璃仍3%、边缘反射50%，文字实色清晰，深壁纸使用可读前景；不靠持续闪烁或60帧动画。

默认7个常驻顶层卡+课间卡最多8个；全局新增组件时验证总数/保护区。只对课间显示此大卡，上课移除并恢复可用桌面，不把临时布局写回全局配置。倒计时和右侧其他卡、绘制/命中使用同一SceneSnapshot；计时卡背景/文字全部穿透。

大面积玻璃背景/标题静态缓存，动态数字采用小范围承载/更新，进入退出才重排；Win7分层窗方案须P0验证，不能每秒UpdateLayeredWindow合成整张大卡/整屏。4K及大数字缓存纳入既有64/96/160MiB与CPU预算，必要时按区域拆分受控顶层承载、统一代次/避让，不创建layered子窗口或额外常驻动画。只在桌面可见且有有效课间时1Hz，PPT前台不SetForegroundWindow、不弹窗、不补画后台帧。

**课堂资料与公共视觉分开**：BREAK_PUBLIC保持公共课间外观，但课堂资料绑定上一节最终有效老师/科目的目录（含临时换课），不是公共资料，不清空或提前读取下一节。列表仍动态读取该目录的发布条目/新增顺序，下一节上课再连同高亮、隐藏大卡原子切换。没有有效上一课、被撤权、换班/跨日或来源不可靠时中性空态；午休/放学等非BREAK状态仍按既有公共策略。
