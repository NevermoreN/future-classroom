## 1. 存储边界与持久对象

对象族：AppSettings、CredentialState、SemesterRevision、CalendarModeAndVersions、ContentRevision、ResourceReference、CommandJournal、CommandResult、SystemOperation、GrantGeneration。此处描述对象职责，不提前发布未经验证的数据库表结构或SQL迁移。

SQLite是单进程嵌入库，统一单写者；附件单独文件存放。配置/内容/命令有各自修订，不用一个全局数字让不相关编辑彼此冲突。涉及同一学期双表/模式切换的原子变更必须处于同一提交边界。

## 2. P1-02：持久化基础步骤

1. 定义Repository与UnitOfWork端口，纯领域不包含数据库连接和SQL。
2. 默认根改为系统解析的 `%ProgramData%\FutureClassroom\`；配置/布局/索引在state，老师/科目资料目录与打开副本分区，另设staging/backups/logs/runtime。部署工具创建本项目目录及最小ACL，固定Windows账号低权限运行；不能回落共享工作目录或继续双写LocalAppData。
3. 数据库有schema版本/初始化标记；迁移先备份，未知高版本拒绝写入，记录错误并只读诊断。
4. 选择耐久/日志模式前做P0崩溃测试；所有同步/flush级别进入依赖和构建记录，不凭吞吐量随意降低。
5. 实现读快照、修订条件提交、命令幂等/槽位接纳序号和操作记录；短事务只在writer执行。
6. 恢复扫描识别未提交文件、待处理命令和系统操作；扫描有批次/时间预算，不阻塞首屏或全部读入内存。

## 3. P3-01：统一内容命令步骤

1. ContentSlot绑定设备和内容类型，先实现文字发布、本地预览、清空、撤销和状态查询。
2. 校验授权/目标/长度/有效期，建立commandId与负载指纹，接受序号持久化。
3. 文字直接准备；图片/分页文档进入P3-02管线。接纳后返回处理中，不回显敏感原文到日志。
4. 提交前重查授权代次、latestSequence与expectedRevision；槽位被更新则SUPERSEDED，修订冲突不自动覆盖。
5. 同一事务写内容修订、命令终态和可查询结果，提交后推快照；渲染可见状态另由窗口模块报告。
6. 撤销明确指定要撤销的当前修订并创建新修订；保留版本有数量/容量上限。

profile按班级/科目/老师隔离，作业按班级/日期/科目/ownerTeacherId修订；教师不能通过整班作业包覆盖其他学科。提醒按班级当天槽，由Web独占写入口，跨日清除活动正文并保留到期标记/脱敏元数据；local及跨午夜旧草稿在提交点拒绝。到期读过滤先于首帧/每次快照，写失败不能让昨天提醒继续显示。

P1-06覆盖ProgramData部署ACL/排他锁、受控LocalAppData迁移、DPAPI部署账号和卸载默认保留；P3-06覆盖profile与老师目录引用；P3-07覆盖共享提醒、按科目作业和自适应派生值。资料、配置目录细则见[多科目手册](07-多科目联动与临时课堂.md)，备份恢复不得复活过期提醒或旧授权。

## 4. P3-02：附件和媒体步骤

1. 资源只来自可信本地文件选择器/受控导入，或绑定已有账号的Web上传。外部请求只使用资源ID/上传句柄，不接受任意URL、UNC或本机路径。
2. 本地文件流式复制、Web上传流式落盘到随机内部ID临时文件；校验账号/句柄/目录归属，限制并发、总字节和超时，不调用远程URL下载附件。
3. 图片以文件头/媒体类型/元数据复核，默认单图10MiB、8MP；先判断尺寸再申请像素缓存，预乘Alpha处理后按显示尺寸缓存。
4. WIC解码串行，有硬内存预算；解码器可能需要原图缓冲，不能因使用缩放器就声称没有原图峰值。坏文件/截断文件/不支持格式明确失败。
5. 文本默认10000字符；分页文档最多50页，清单有序，页大小沿用图片限制，当前页之外只受限预取。拒绝ZIP路径穿越和可执行附件，首版不通过任意压缩包扩大格式范围。
6. 资源验证完成后落到受控最终文件，再提交引用；旧资源先保留引用直到新版本成功。上传/导入失败不清空旧内容。
7. 清理取消、失败和超限任务的临时文件。旧任务完成必须经过序号检查，较新任务失败也不复活旧准备任务。

默认上传或导入准备并发2、解码1、图片缓存32MiB、磁盘缓存200MiB。旧内容/新内容/临时上传/未引用资源分别计账；不能只算缓存文件而遗漏临时上传或复制导致磁盘无限增长。已被有效内容引用的文件不可为达到配额随意删除；不足则拒绝新上传并报告原因。

这里200MiB为可重建媒体缓存，不是教师原件配额。当前初始单件50MiB、原件总量2GiB，图片限制沿用；老师资料原件/独立图片缓存/打开副本分别计账。课堂资料受控保存白名单原件，列表无缩略图/封面；后台不自动调用Shell/Office渲染，用户主动本地点击由M17调用系统关联软件。可执行/脚本/宏/快捷方式拒绝，文件名行提供本地open动作，仅打开白名单资料而不执行任意命令。浏览器通过鉴权资源ID取图，不能静态暴露ProgramData。

## 5. 文件与事务崩溃点

| 崩溃位置 | 恢复行为 |
| --- | --- |
| 临时上传/复制未完成 | 无提交引用，清理未完成文件；标记资源需重新上传，客户端显式恢复，不自动提交残缺内容 |
| 资源已落盘、数据库未提交 | 孤立文件按宽限期和引用检查回收 |
| 数据库事务中断 | 打开后按数据库恢复结果确定有效修订，不人工删日志文件 |
| 提交成功、快照未发布 | 重载最新修订并渲染，命令仍为已提交 |
| 已提交、Web响应丢失 | 按原commandId查询持久结果；业务不重新执行，不撤销内容 |
| 旧数据迁移不兼容新程序回退 | 使用兼容备份或拒绝写入；不只换exe继续写 |

宽限期防止正在使用资源被清扫；活动任务清单、提交引用和清理批次之间需协调。删除操作先判断引用与状态，删除失败记录重试，不把文件系统错误视为数据库不存在。

## 6. 去重和留存

业务commandId用于操作幂等，资源哈希用于字节复用，两者不能替代。同图用新commandId明确发布两次可以形成新修订；同一commandId、同一负载重试返回原结果，负载不同拒绝。

CommandJournal记录已接纳命令与准备状态，CommandResult记录终态及提交修订；客户端在响应丢失后以原ID查询，不设置消息收发箱或后台结果投递队列。恢复只继续授权、有效期和资源仍有效的准备任务；文件打开动作不重放。

P3冻结有界的命令/结果保留期限，并由API公布可查询及可重试窗口。保留期内同ID返回已有结果；保留期外不自动把旧ID当作新操作执行，而应返回窗口已过期并要求老师核对后显式发起新操作。具体过期识别与拒绝策略须随接口契约冻结并通过重试/恢复测试，不承诺永久恰好执行一次。

## 科目颜色与胶囊显示补充

学校配色保存原始不透明RGB及修订，最终低饱和effectiveRgb由统一纯规则派生，不由各组件随意调色；底色开关关闭保留原值，恢复/升级后重新派生。两种显示模式与当前课状态决定胶囊填充/描边，不从历史布局恢复数字列或填色金边。备份与ProgramData规则不变。详见[视觉手册](09-科目配色与简洁模式.md)，P1-04/P2-07/P4-10/P6-06按各自职责落实，Q20验收。

R30存储补充：科目显示设置追加subjectFillOpacityPercent（默认3），课程独立coursePillFillOpacityPercent（默认20），组件布局追加componentOpacityPercent（默认100），均为整数0–100；按各自修订及作用域保存，旧字段迁移时避免重复Alpha合成，备份恢复保留。0%不删除资料或改变课程。见视觉手册第6节/Q20。

语音资源单独存ProgramData的voice/staging与voice/active，按16MiB配额/队列引用回收；常规教学资料备份不纳入临时音频正文或活跃队列，恢复不自动播旧语音，终态且设备释放后删除音频，仅留有界脱敏状态审计。


## D11 Rust存储与资源补充

rusqlite连接仅由writer线程拥有；内层DocumentStorePort/ContentStorePort由fc-ports定义，应用不导入具体Connection。guard/after_commit只读可信内存状态，不做文件/KDF或重入数据库；已COMMIT而权威发布panic须先进入全局FAULTED，拒绝旧授权敏感读取/写入/新副作用，撤销准备与播放代次并隐藏展示，直至受控重启。SQLite bundled实际版本及锁定依赖必须记录，数据格式与升级兼容使用独立合成样例验证。原件管线用纯Rust ZIP/deflate/XML校验不扩大格式范围，XML禁DTD且节点有界；Windows图片仍须WIC实际解码，没有适配器明确失败而不只凭文件头通过。
