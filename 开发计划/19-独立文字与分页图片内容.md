# 独立文字与分页图片内容

总计划1.31 / D11，第十八轮，2026-10-31（北京时间）。细化R01、R20、R22、R25、R33及P1-04/P3-01/P3-02/P3-08/P4-11，保持十二crate、33条内部依赖和既有教师四业务边界。实际构建、实机、失败及清理证据分别见[实施记录](10-实施进度与验证记录.md)。本文描述已接入的实现契约，不代表整项验收通过。

## 内容身份与本地操作

独立文字和独立图片是布局树中的真实叶节点，不复用作业、提醒或课堂资料槽位。身份为`ContentSlotKey { scope, node_id }`；科目范围包含精确班级、科目和实际教师。节点ID保持高水位，不复用退役ID，不允许原ID更换内容类型。样式与正文分别保存；八种内置组件的设置集合不因此扩大。

仅新鲜、精确的本地主管理员会话能够管理内容。布局先保存为clean状态，再从所选节点进入内容管理。文字、TXT、图片追加/移除/排序、清空和撤销经过摘要确认；撤销携带明确的目标内容修订。重新读取需要保护未保存草稿，锁定或会话变更取消旧确认。不能把未取得后台完成结果显示成“未保存”或擅自重发。

教师网页继续只有本人作业、本人课堂资料、获准的共同提醒和语音入口；本轮没有增加通用文字、图片或布局写API。桌面访客翻页能力不产生管理员actor，也不延长管理闲置会话。

## 发布与失败顺序

固定共享执行池仍最多两个worker、八个排队描述和4MiB队列载荷。输入为有界文字或原生选择器产生的不透明选择对象；外部路径、文件句柄和像素不进入领域文档或普通队列载荷。

1. worker廉价固定源句柄与长度，产生随机意图摘要；此时不复制、哈希或调用WIC。
2. 唯一writer持久化Begin，核对节点、精确会话、预期修订和最新发布序号；仅新增图片页预约版本ID与字节额度。
3. worker以同一受保护句柄复制、实际SHA-256、完整格式校验、flush和不可覆盖发布。重新排序的既有页也核对所属节点、原件摘要和WIC结果，不重新计费或制造新ID。
4. 不可克隆的Prepared证明绑定Begin、真实正文摘要和媒体引用。唯一writer在事务求值和实际COMMIT前重复精确会话、当前树、序号、CAS及任务执行检查；任务取消、单调期限、pool停止或故障不能靠先前检查继续提交。
5. 准备对象与所有实际文件占用退出后，worker才结算预约。较晚失败的B不能复活已经被B替代的A；旧已提交内容保留。COMMIT后才取消的结果属于未知完成，重新打开和命令回执核对已经提交的版本，不能回滚它。

`JobContext::execution_fence`只复制原任务的内存存活检查，不授予身份。敏感文件操作遇AuthorityUpdating暂停，继续检查取消和预算；Updating既不是可继续读文件的许可，也不立即等同永久撤权。所有SQLite等待与文件/解码工作都在worker，UI只处理有界事件与结果。

## 内容与资源预算

| 资源 | 边界与所有权 |
| --- | --- |
| 文字 | 最多10,000个Unicode标量、40,000个UTF-8字节；原生多行Edit最多20,000个UTF-16代码单元，完整支持10,000个emoji |
| TXT | 严格UTF-8（可有BOM）或带BOM的UTF-16LE/BE；保留合法换行和格式；拒绝非法序列、替换解码、截断代理项及不允许的控制字符；输入读取64KiB封顶 |
| 图片文档 | 显式有序页，最多50页；PNG/JPEG/BMP，每页最多10MiB、800万像素；只允许受支持的系统解码器与单帧 |
| 原件 | 与课堂资料共用2GiB原件总额度，独立注册表和受保护命名空间；当前内容与一个可撤销版本都计入引用 |
| 解码与缓存 | WIC验证和显示准备共用一个物理解码准入；进程共享图片缓存32MiB、文字缓存4MiB；实际Arc离开前不退款，清除查找项不等于释放物理占用 |
| 原生绘制 | 沿用16MiB应用RGBA/DIB总预算；预乘BGRA光栅经CPU合成到现有DIB，不另建未计费的图片位图缓存 |
| 时间 | 每文件CPU10秒、墙钟30秒；同步WIC/系统调用未真正返回时仍保留worker和物理内存所有权；不能用取消标记伪造资源已释放 |
| 状态载荷 | DesktopFacts只带轻量描述、精确内容/视图修订及页引用，不携带正文、路径或像素；既有2MiB事实预算保留 |

注册表目前最多8,192个媒体记录、16,384个内容head和65,536个回执。计数达到本阶段容量时明确拒绝，不静默淘汰仍用于幂等/撤销的记录；长期保留和容量扩展仍需后续方案与验收。

## 场景、预览与翻页

当前课程仅装入实际选中的公共Outlet或精确科目树，课间不继承上一课独立文字/图片；既有课堂资料的课间保留规则独立。文字在worker按精确槽位、修订和实际SHA装入有物理额度的TextFrame，图像按完整媒体引用从受控原件准备。所有图像批次在IO前后校验全局修订和当前课程；缓存命中不能绕过这次场景验证。

测量与原生使用同一份完整正文/图片几何。图片按Contain等比居中，不裁切正文、不放大原始光栅；手动上一页/下一页具有最小44DIP操作区。图片页号与视图修订单独CAS，不改变内容发布序号。只有已经安装的同代次、同全局修订、同内容和视图修订场景可以翻页；旧代次、过期课程或晚返回结果不能改页。

替换场景、进入管理预览或显示不可用时释放旧原生卡片及文字/光栅Arc，避免旧物理占用使新内容永远无法准入。图片准备30秒、翻页5秒的UI监督只发出取消；票据在worker实际退出后才归还。

主管理员预览使用精确本地管理会话，允许查看非当前课或历史科目配置，不伪造实际授课选择。内置组件明确使用示例，独立节点读取实际已发布内容；仅真正新建且超过持久节点高水位的草稿节点可显示空内容。退役ID、已有ID改类型或科目profile身份变化明确拒绝。预览固定同一个时间和来源修订，worker准备真实TextFrame与图片Arc，原生画布成功安装前后再次检查精确管理状态；预览不保存修改。

## 回收与重启

`profile-content/originals`和`quarantine`带独立所有权标记，仅接受规范版本文件名、普通单链接文件及受保护父目录。运行时回收只处理Unreferenced/Retiring：精确注册修订退休、实际排他删除、最后Finalize退款。媒体行的`charged_bytes`保留原预约大小；Removed行不再计入catalog总占用，不能以该字段清零判断退款。文件仍被占用时继续计费；Reserved只由原准备worker真正退出后结算，不因TTL到期被另一个任务夺走。

节点删除/重置在布局事务中移除当前与Undo引用。应用通过同一执行池周期回收，每次最多检查128条记录，使用应用独有的有界内存游标续扫；游标在短锁内保存，不依赖可能被取消丢弃的结果。到尾部回绕，前部占用或冲突不会永久挡住后部资源。票据未实际终止时不启动另一个同类维护任务。单个同步系统调用未返回或每次均用尽预算时，仍不能据此证明硬期限或无条件最终性；本轮游标修复的是已完成分段工作反复从头扫描的问题。

启动恢复仅在拥有部署实例锁、没有上一轮准备worker存活时调用。先完整验证命名空间和注册表，核对所有Referenced原件的长度与真实SHA，之后才处理孤儿、旧Reserved、Retiring和已Removed的物理残留。缺失/错误原件、未知命名、链接或损坏状态进入修复，不能删除其他文件后继续当作新安装。数据库回退后留下的本应用孤儿也需在完整核对后清理。运行中的周期维护不能调用启动恢复来结算Reserved。

## 验证边界

保留纯规则、真实SQLite/DPAPI、WIC、原生窗口和完整隐藏工作台各自的证据，绑定实际源码与运行EXE的SHA。最初的编译/夹具失败和后续修正分别保存，不用后续PASS改写旧结果。

Windows11授权测试电脑可验证本机Win32/WOW64链路；它不自动代表Win7 SP1 x86、Win10、正式MSVC、希沃触控/DPI/PPT或可见桌面验收。严格5秒P0、可信TLS/实际生产监听、安装升级卸载及72小时长稳仍保持各自未完成门槛，完整开发目标继续active。
