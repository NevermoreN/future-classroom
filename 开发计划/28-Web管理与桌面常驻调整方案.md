# D12：Web管理、页面登录与桌面常驻调整

日期：2026-11-04。依据用户本轮五项要求，本文件与总计划1.46组成D12基线；与D11的原生设置、配对登录、闲置重登录、前台隐藏及图标约定冲突时，以本文件为准。未涉及的业务、数据、权限、兼容性与资源约束继续有效。本文定义需求，实际实现、安装交付与验证范围见[实施记录](10-实施进度与验证记录.md)，不能仅凭计划文本标为通过。

## 1. 全部设置迁至Web

- 完全移除产品自建的Windows本地设置、登录、初始化和管理工作台窗口，不保留原生设置备用入口。Windows端继续负责透明桌面绘制、托盘、音频及系统操作；不嵌入浏览器内核，使用系统默认浏览器打开Web。
- 托盘右键“查看状态”直接打开本机Web状态页；“设置”直接打开本机Web设置页。未登录先进入同一Web登录页，成功后返回原目标。入口不能再次弹出原生口令框。
- Web覆盖现有全部管理能力：首次学校/管理员初始化、账号/密码/角色/任教与默认老师、科目、学期课表/单双周/校历、显示与玻璃参数、组件树和布局编辑/预览、独立文字与图片、作业/资料/提醒/录音、运行状态/诊断、网络来源与HTTPS证书、自启动、备份/导入恢复/重置。保留原有影响预览、确认/取消、修订冲突与后台命令结果，不以删掉原生入口代替功能迁移。
- 安装和首次启动先准备本机回环Web入口及每安装独立的HTTPS证书，不能依赖已删除的原生设置才能启用Web或生成证书。本机入口与局域网开放分别控制；局域网仍需明确配置来源范围，使用HTTPS的IP地址加端口，证书包含实际访问IP SAN。项目可自动生成证书并提供公开证书导出/信任说明，不随安装包分发通用私钥。
- 初始化仅在确实未初始化的安装开放；数据或凭据损坏不能借机重新注册管理员。配置错误通过本机Web提供可读诊断和受控修复，不恢复原生管理窗口。操作系统的文件选择框、证书信任提示和UAC不属于产品设置UI；系统权限要求仍由Windows决定。
- 继续使用同一权威数据与应用用例，不另造Web专用数据库。升级保留账号/密码、任教、课表、布局、资料原件/索引、设置和命令历史；成功与回滚均不能因UI迁移丢失数据。

## 2. 用户名密码登录与页面会话

- 管理后台仅用已有用户名和密码登录，不要求配对码、设备申请、本机管理员批准、额外验证码或恢复码登录。首次初始化创建管理员属于安装引导；灾难恢复另行保留受控维护流程，不能作为第二套管理登录入口。
- 全局管理员在Web管理全部配置；教师仍只能管理其授权业务。登录方式统一不改变角色边界。桌面公开功能按钮继续免验证；课表、时钟、日历和日期倒计时继续纯展示。
- 同一打开页面中的路由切换、刷新、API请求、断线重连和普通闲置不重复要求输入用户名密码，废止默认5分钟闲置后弹出重登录。后台每次请求仍校验会话、角色、授权代次和修订，不能把“不反复输入”实现为免鉴权API。
- 用户确认的体验边界是“连接时不要重复验证用户名密码，只有在关闭网页下次打开时才需要重新验证用户名密码”。采用标签页会话：临时页面凭据仅存sessionStorage，当前访问令牌存内存；不把共享登录Cookie或localStorage当作自动登录依据，不保存密码。刷新或网络恢复时用页面凭据自动恢复访问，普通关闭页面后临时凭据随标签会话结束，新打开的页面进入用户名密码登录。
- 移除上一轮自行增加的“任意浏览器恢复、复制标签均必须严格判别为重新登录”验收要求，不为浏览器特殊恢复行为构造额外状态机。使用标准标签页存储语义，浏览器自身的恢复/复制行为另列适用边界；不宣称服务端能即时可靠识别关闭事件。退出按钮主动清除页面凭据并注销；不依赖unload作为唯一清理依据。
- 会话恢复仍核对账号状态与授权代次。普通闲置、后台标签页冻结或心跳中断不能吊销仍打开页面的恢复凭据，短期访问令牌过期由页面静默恢复，不重新派生密码。服务端缓存/临时工作有界回收与页面登录凭据有效性分开，避免把资源回收变成反复登录。
- 主动退出、修改本人密码、账号停用、管理员撤权等明确安全事件应立即使相应授权失效，可以要求重新登录；不把这些事件误写成普通连接重验证。密码仍加盐派生保存，保留失败限速、HTTPS、来源限制和CSRF防护。旧配对授权不自动变为新管理登录授权。

## 3. 透明桌面持续显示与退出

- 将“其他应用前台时隐藏”改为正常Windows用户桌面上持续可见的非激活置顶透明层。打开、切换或最大化其他程序，以及PPT/WPS/希沃教学软件全屏、浏览器管理页面、Win+D/Win+M等操作，均不能导致该层被隐藏、最小化或压到其他应用后面。
- 保留根层透明和背景鼠标/触摸/白板笔穿透，仅明确公开按钮及既有资料操作区域接收输入；不能为了置顶而抢焦点、挡住整屏输入或改变纯展示组件的点击规则。已发布内容按当前真实课堂状态更新，不复活旧老师或旧提醒。
- 关闭设置网页、Web退出登录或管理授权过期不退出桌面程序。正常用户主动退出入口为右键Windows任务栏托盘图标“退出程序”，不要求先登录管理后台；退出时完成音频停止、请求取消及资源回收。
- 用户原文“除非邮件windows任务栏退出”按“右键Windows任务栏托盘退出”执行。锁屏、UAC安全桌面、注销和系统关机属于Windows控制边界，不尝试覆盖安全桌面或阻止系统退出；返回同一用户桌面后应自动恢复可见状态。异常崩溃不能被宣称为绝不会退出。
- 窗口使用非激活置顶层级，收到前台/显示器/Shell变化后合并处理层级与几何修正；不以高频定时器反复抢置顶。正常桌面及教学软件全屏是交付场景；其他置顶窗口、独占显示和系统界面由Windows共同仲裁，不把单次HWND_TOPMOST调用当作永远最高层的保证。遇到冲突记录具体软件/模式并修正，不恢复旧“外部前台主动隐藏”策略。

## 4. 启动快捷方式与生成图标

- 正式安装后同时提供Windows桌面启动快捷方式和开始菜单“未来教室”启动项；按Windows键后可搜索找到。快捷方式指向受控安装主程序，包含正确工作目录与图标；重复启动复用同一驻留实例，不重复生成窗口或后台进程。
- 升级/修复保留或修复本项目快捷方式且不重复创建；卸载只清理本项目拥有的项，不删除用户其他快捷方式或教学资料。默认遵循现有当前用户安装范围，全用户安装仍遵守实际权限。
- 所有项目自行提供的图标使用imagegen生成并落地：应用EXE、安装器、桌面/开始菜单/托盘、Web品牌/favicon，以及导航、功能和状态图标。系统自身图标不在生成范围；不能用默认程序图标、占位图或通用图标库替代后宣称完成。
- 与现有蓝白Web风格统一，生成透明背景主素材及必要状态变体，并制作适合小尺寸识别的版本；按实际使用输出多尺寸ICO与PNG等产物，覆盖16至256像素等Windows所需尺寸。保留提示词和资产来源记录，接入程序资源、安装包和Web构建，不只放入设计目录。实际生成、构建和安装情况分别记录，不以本条需求定义代替完成证据。

## 7. 本机入口、维护模式与迁移契约

本节落实2026-11-04审查后的用户确认，替代“实现阶段再决定”的架构空缺。保持十二crate和现有Schannel/IOCP实现，不另造中心服务、数据库或独立常驻维护进程。

### 本机入口和证书

- 本机控制面与可关闭的局域网业务监听分开拥有生命周期和配置；两个监听共用原来的单个IOCP/SSPI执行域及固定连接槽，本机保留接纳容量。控制面只绑定回环地址，在18443–18452固定范围选择实际可用端口。M00在原进程内存中发布实际地址；托盘直接读取，重复启动向持有实例锁的原进程发送打开请求，避免依赖可能过期的地址文件。局域网原HTTPS IP加端口保持独立。
- 本机与局域网可分别选择证书：本机保持自建回环证书，局域网保留选择合法CurrentUser MY服务端证书指纹的能力。单个SSPI线程最多拥有两个明确的凭据对象，不增加线程或执行池；每个上下文固定绑定实际接纳监听的作用域。更换局域网证书必须等原局域网上下文及接纳操作真实退休，再由原SSPI线程释放旧凭据、核对新证书的时效、SAN、服务端用途和私钥，并在成功回执后开放新监听；期间本机证书与上下文不变。
- 每安装生成独立密钥和含127.0.0.1/实际局域网IP SAN的证书，安装/启动端口在打开页面前完成本机当前用户证书信任准备和回读；其他教师设备仍需导入公开证书。不能把公开证书导出页本身当成首次浏览器信任的唯一来源。
- 监听和证书修改采用“准备新配置并验证→提交配置→切换→回读”的流程；切换失败保留原可用本机入口及明确错误。局域网配置不能改掉本机控制面的回环绑定或关闭它；不以HTTP明文降级来处理证书错误。
- 本机控制面自身损坏时，托盘/受控程序的现有修复启动路径只进行自有网络配置与证书的准备/修复后重新打开维护Web，错误写脱敏诊断及本机说明；不弹产品原生设置、不擅自删除数据或覆盖第三方证书。无可用监听或证书时明确报告失败，不假称Web已可访问。初始化写入仅限本机回环、严格Host/Origin及一次性未初始化CAS，局域网不能抢注首管理员。

### 恢复与重置的控制面

- M00拥有本机维护控制面和操作进度快照，业务Backend、writer、音频、Shell及局域网监听属于可停止的业务运行域。恢复确认前必须有全局管理员用户名密码会话及完整预检；确认后接纳一个不可扩权的操作标识，本机控制面仅允许原页面读取该操作脱敏进度/结果，不允许继续管理读写或用旧会话提交新命令。
- 恢复仍按既有安全代次、真实排空、join与冷切换顺序执行。业务文件Hub在原共享线程池仍可执行时完成负向清理，实际结束后才把线程池移交冷协调器。停止业务HTTP不等于关闭本机维护HTTP；维护进度及取消仅读取独立内存快照，不访问旧数据库或排入已停止的线程池，也不阻碍冷切换。
- 完成后显示结果并要求退出后重新启动；新进程先协调受保护恢复日志，再打开唯一业务Backend、重建场景并重新登录，账号安全底线不回退。此选择沿用原单writer及原生执行域的所有权约束，避免在原进程冷切换后重开业务造成两个运行代次交错。恢复失败或中断进入只读维护状态；结果由受保护恢复日志重建，不依赖旧网页存活。
- 原`--repair`改为仅持有部署锁的本机维护Web宿主，不创建原生修复窗口。无密码清除仍要求部署用户主动从本机修复启动路径进入，仅可明确放弃全部旧部署数据；页面采用该次OS启动限定的操作能力、严格回环/同源、两次明确确认和既有冷许可，不访问旧资料、不授予管理会话，局域网及普通未登录页面不能发起。此能力只确认本次破坏性维护，不构成另一种管理后台登录方式。
