# D12：Web管理、页面登录与桌面常驻调整

日期：2026-11-04。依据用户本轮五项要求，本文件与总计划1.45组成D12基线；与D11的原生设置、配对登录、闲置重登录、前台隐藏及图标约定冲突时，以本文件为准。未涉及的业务、数据、权限、兼容性与资源约束继续有效。本文是待实施需求，不能作为功能已交付或测试通过的证据。

## 1. 全部设置迁至Web

- 完全移除产品自建的Windows本地设置、登录、初始化和管理工作台窗口，不保留原生设置备用入口。Windows端继续负责透明桌面绘制、托盘、音频及系统操作；不嵌入浏览器内核，使用系统默认浏览器打开Web。
- 托盘右键“查看状态”直接打开本机Web状态页；“设置”直接打开本机Web设置页。未登录先进入同一Web登录页，成功后返回原目标。入口不能再次弹出原生口令框。
- Web覆盖现有全部管理能力：首次学校/管理员初始化、账号/密码/角色/任教与默认老师、科目、学期课表/单双周/校历、显示与玻璃参数、组件树和布局编辑/预览、独立文字与图片、作业/资料/提醒/录音、运行状态/诊断、网络来源与HTTPS证书、自启动、备份/导入恢复/重置。保留原有影响预览、确认/取消、修订冲突与后台命令结果，不以删掉原生入口代替功能迁移。
- 安装和首次启动先准备本机回环Web入口及每安装独立的HTTPS证书，不能依赖已删除的原生设置才能启用Web或生成证书。本机入口与局域网开放分别控制；局域网仍需明确配置来源范围，使用HTTPS的IP地址加端口，证书包含实际访问IP SAN。项目可自动生成证书并提供公开证书导出/信任说明，不随安装包分发通用私钥。
- 初始化仅在确实未初始化的安装开放；数据或凭据损坏不能借机重新注册管理员。配置错误通过本机Web提供可读诊断和受控修复，不恢复原生管理窗口。操作系统的文件选择框、证书信任提示和UAC不属于产品设置UI；系统权限要求仍由Windows决定。
- 继续使用同一权威数据与应用用例，不另造Web专用数据库。升级保留账号/密码、任教、课表、布局、资料原件/索引、设置和命令历史；成功与回滚均不能因UI迁移丢失数据。

## 2. 用户名密码登录与页面会话

- 管理后台仅用已有用户名和密码登录，不要求配对码、设备申请、本机管理员批准、额外验证码或恢复码登录。首次初始化创建管理员属于安装引导；灾难恢复另行保留受控维护流程，不能作为第二套管理登录入口。
- 全局管理员在Web管理全部配置；教师仍只能管理其授权业务。登录方式统一不改变角色边界。桌面公开功能按钮继续免验证；课表、时钟、日历和日期倒计时继续纯展示。
- 同一打开页面中的路由切换、刷新、API请求、断线重连和普通闲置不重复要求输入用户名密码，废止默认5分钟闲置后弹出重登录。后台每次请求仍校验会话、角色、授权代次和修订，不能把“不反复输入”实现为免鉴权API。
- 关闭该页面/标签后再次打开必须重新输入用户名密码；新标签或新窗口不能仅凭另一页面的登录自动进入。不得保存长期自动登录凭据或提供“记住密码并自动登录”。浏览器自己的密码管理器由用户控制。
- 会话实现须区分当前页面的刷新/重连与关闭后重新打开，处理浏览器重启、页面恢复和复制标签；不能只靠共享Cookie、持久localStorage、sessionStorage或不可靠的unload回调宣称达标。实现阶段选定页面凭据和服务端有界租约/回收方案，并以实际浏览器行为验收；租约用于回收，不在正常页面存续时制造反复登录。
- 主动退出、修改本人密码、账号停用、管理员撤权等明确安全事件应立即使相应授权失效，可以要求重新登录；不把这些事件误写成普通连接重验证。密码仍加盐派生保存，保留失败限速、HTTPS、来源限制和CSRF防护。旧配对授权不自动变为新管理登录授权。

## 3. 透明桌面持续显示与退出

- 将“其他应用前台时隐藏”改为正常Windows用户桌面上持续可见的非激活置顶透明层。打开、切换或最大化其他程序，以及PPT/WPS/希沃教学软件全屏、浏览器管理页面、Win+D/Win+M等操作，均不能导致该层被隐藏、最小化或压到其他应用后面。
- 保留根层透明和背景鼠标/触摸/白板笔穿透，仅明确公开按钮及既有资料操作区域接收输入；不能为了置顶而抢焦点、挡住整屏输入或改变纯展示组件的点击规则。已发布内容按当前真实课堂状态更新，不复活旧老师或旧提醒。
- 关闭设置网页、Web退出登录或管理授权过期不退出桌面程序。正常用户主动退出入口为右键Windows任务栏托盘图标“退出程序”，不要求先登录管理后台；退出时完成音频停止、请求取消及资源回收。
- 用户原文“除非邮件windows任务栏退出”按“右键Windows任务栏托盘退出”执行。锁屏、UAC安全桌面、注销和系统关机属于Windows控制边界，不尝试覆盖安全桌面或阻止系统退出；返回同一用户桌面后应自动恢复可见状态。异常崩溃不能被宣称为绝不会退出。

## 4. 启动快捷方式与生成图标

- 正式安装后同时提供Windows桌面启动快捷方式和开始菜单“未来教室”启动项；按Windows键后可搜索找到。快捷方式指向受控安装主程序，包含正确工作目录与图标；重复启动复用同一驻留实例，不重复生成窗口或后台进程。
- 升级/修复保留或修复本项目快捷方式且不重复创建；卸载只清理本项目拥有的项，不删除用户其他快捷方式或教学资料。默认遵循现有当前用户安装范围，全用户安装仍遵守实际权限。
- 所有项目自行提供的图标使用imagegen生成并落地：应用EXE、安装器、桌面/开始菜单/托盘、Web品牌/favicon，以及导航、功能和状态图标。系统自身图标不在生成范围；不能用默认程序图标、占位图或通用图标库替代后宣称完成。
- 与现有蓝白Web风格统一，生成透明背景主素材及必要状态变体，并制作适合小尺寸识别的版本；按实际使用输出多尺寸ICO与PNG等产物，覆盖16至256像素等Windows所需尺寸。保留提示词和资产来源记录，接入程序资源、安装包和Web构建，不只放入设计目录。本轮仅写计划，图标生成在实施阶段进行。
