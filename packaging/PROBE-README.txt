未来教室 FutureClassroom 0.1.1 — Windows x86 使用说明

本包包含正常原生应用；附带 web 目录时也包含教师网页。可用功能、现场验收和
长期运行证据分别记录，不将打包成功解释为全部 D11 要求验收通过。
历史文件名 PROBE-README.txt 及 manifest.json 的 development-probe、NOT_VALIDATED、
PARTIAL_NOT_VALIDATED 为现有打包协议分类，保留以兼容 MSI 生产器；不表示正常
图形界面或教师 HTTPS 尚未实现，也不证明本包已经通过 CI、现场或正式发布门槛。

开始使用

1. 将 ZIP 完整解压到固定目录，不要只从压缩包内运行 EXE。保留同目录的许可证、
   manifest.json 以及 web 子目录。若使用 MSI，按附带 MSI-CANDIDATE.txt 安装。
2. 双击 fc-bootstrap.exe 打开工作台。正常启动使用 Windows GUI 子系统，不弹控制台。
   首次运行在 ProgramData 的 FutureClassroom 专属受保护目录准备数据库和当前
   Windows 用户的 DPAPI 密钥；按向导设置学校及主管理员口令，没有默认密码。
   保管恢复码；后续仍使用原 Windows 账号运行，不直接搬动受保护数据目录。
3. 先创建班级、科目、教师账号及任教范围，再配置课表和作息。课表、显示、布局等
   页面先编辑草稿，点击相应保存后生效；取消不写入，锁定后原账号可继续其草稿。
   教师使用管理员发放的账号并完成首次改密；设备配对不会替代账号或增加权限。
4. 在桌面显示设置中选择显示屏、时钟、组件样式及公共布局；按需要设置精确
   班级/科目/教师配置，添加文字、图片页或资料。布局预览中的内置组件使用示例，
   独立内容使用已发布版本；预览不是当前课堂截图。
5. 关闭工作台后会锁定本地管理会话。课堂卡片按当前课程和配置显示；外部应用、
   管理窗口或无效 Windows 会话时隐藏。仅明确功能按钮接收点击，其他区域穿透。
   临时换课/恢复原课向任何使用者开放，无需账号或口令；不修改基础课表。
   课程表、时钟、日历/日期/倒计时纯展示，不能点击或翻页。
6. 如需登录自启动，由主管理员在工作台核对期望、实际及当前程序路径后明确开启。
   解压 ZIP 本身不会开启自启动。程序启动只核对实际状态，不自动反复修复。
   正常退出须主管理员授权，有未保存草稿时先处理退出提示。

本地功能可离线使用。资料支持 PNG/JPEG/BMP/TXT/PDF/PPTX/DOCX/XLSX，校验后
存入受控原件；点击资料会先创建独立副本，再请求本机关联程序打开。请自行准备
相应阅读软件。本程序不会安装 Office 或修改默认文件关联。原件单件上限50MiB，
图片单页10MiB/800万像素，共享原件总额2GiB；管理页提供副本占用和到期清理。

教师网页：需要学校 IT 配置后明确启用

1. 确定白板固定域名或 IP、HTTPS 端口及允许来源 CIDR。教师设备必须能访问该网络。
2. 为实际运行程序的 Windows 账号准备当前用户“个人/MY”中含私钥的服务器证书。
   证书域名/IP备用名称须匹配访问地址、在有效期内，且教师设备信任其证书链。
   程序不自动签发证书、导入根信任、分发私钥或开放防火墙。
3. 由 IT 按端口、程序及明确来源网段配置必要入站规则，并保留变更记录。
   正常宿主使用 Winsock/Schannel，不需要历史 HTTP.sys 探针的 URL 预留或 SSL 绑定。
4. 主管理员进入“教师设备与配对”→“配置本机HTTPS”，填写域名/IP、端口、
   1至16项明确 CIDR 及40位十六进制证书引用。没有默认端口或来源网段。
   域名须唯一解析；多地址时使用证书匹配的明确地址。
   保存后点击“检查已保存的证书”，返回设备页明确“启用教师连接”。
   保存、证书检查或显示本机正在运行，都不能代替远端可达性与信任检查。
5. 教师访问 https://域名或IP:端口/fc/ （IPv6地址加方括号）。若浏览器报告证书错误，
   先由 IT 修复信任和名称匹配，不靠忽略错误使用录音功能。
   主管理员“开启短时配对窗口”，教师输入已有账号登录名、设备名称和当次短码，
   主管理员核对教师及设备后批准。配对只授予该账号原有范围。
6. 教师可管理本人作业和资料、共同编辑今日提醒，或按住录音发起语音播报。
   日期以白板为准；录音正常松开发送、上滑取消，默认共播放3遍。上传成功不等于
   已播放或听到声音。结果未知时先查询原操作，不自动重发；COMMITTED表示持久化，
   不表示当前课堂已经显示。主管理员可在本机收紧语音限制或停止全部播报。
7. 换证书或地址前，先明确“停用教师连接”并等待传输清理完成；本地工作台仍可用。
   白板关闭后不能接收教师操作。web 目录缺失或校验失败时，不具备网页托管条件。

备份、恢复与更新

更新使用本项目安装维护流程，保留原学校资料；请先从工作台导出备份并另存到
部署目录外。不要删除 ProgramData 数据库来“重装”。普通备份不含可复用账号凭据，
也不恢复活跃语音任务。恢复按界面复核影响，等待实际关闭和冷切换后重新登录。
显式映射恢复须将来源班级、科目、账号逐一映射到当前目标，不按编号或名称自动
匹配；保留目标当前账号凭据与授权，完整替换教学集合，不是部分合并。

无恢复码且决定放弃全部本机资料时，才使用登录/修复页的“清除后重新初始化”，
或在原程序实际关闭后运行 --repair。向导要求分别确认资料丢失与全新设置；取消
不解锁旧资料。确认会清除本机学校、账号凭据、资料、图片、语音及部署目录内备份。
部署外已另存副本与 Windows/其他应用配置不属于该清除范围。清除后重新启动设置。
卸载默认保留学校资料；能力3正常 Setup 卸载清理本程序精确自启动项。手工配置的
证书信任、防火墙规则由原部署人员按记录处理，不删除学校 CA 或其他服务规则。

诊断及实际限制

无需运行开发探针才能使用本程序。主管理员可打开“运行诊断（只读）”，手动查看
绘制方式、系统合成报告及进程内存/句柄；第二次刷新显示对应间隔的 CPU 读数。
没有后台轮询；短间隔读数不表示性能或长稳达标，系统合成报告也不表示额外模糊已开启。
需要支持人员诊断时，可在 PowerShell 中显式接收输出并等待退出：
  .\fc-bootstrap.exe --version | Out-Host
  .\fc-bootstrap.exe --self-check | Out-Host
随后读取 $LASTEXITCODE，0为该命令成功，非0为失败。正常 GUI 程序直接从命令行
启动时，不能依赖控制台自动等待或显示输出。--self-check 使用隔离临时数据并清理；
其他 --*-probe 属于开发诊断，不能用单项通过证明正常学校部署或全部功能验收通过。

兼容设计目标：Windows 7 SP1 x86、Windows 10、Windows 11；ARM64未承诺。
Win7/Win10实机均为 NOT_RUN（用户不安排当前及后续测试），保留兼容设计和构建检查，
不写成已实测兼容，也不等待设备。Win11有限运行、MSVC编译及安装链证据不等于
全部课堂触控、白板笔、DPI/PPT避让、真实手机录音/可听效果、校园网络或72小时验收。
本包不会通过修改系统主题、抓取用户桌面或扩大联网来补齐上述证据。
首请求头预算初值5秒，校园网络校准及完整场景验收另行记录；不声称任意 OS 调度
都能保证对端物理断开严格不超过5秒。缺少现场/长稳证据的项目仍为未验证。
静态 PE 导入检查不能证明系统兼容；系统更新或运行库不在本包内。

包内容与许可

manifest.json 记录本包目标、工具链声明、逐文件大小/SHA-256、功能范围和 PE 风险，
打包脚本不编译或执行程序，也不自动认证二进制来源。frontend.included=false 表示
没有附带浏览器产物，本地功能仍可用；true 表示附带经大小/摘要校验的 web 资源，
不表示证书、客户端信任或校园部署已配置。解压后保持资源与 EXE 相邻。
LICENSE 为项目许可；原生及网页第三方组件许可见 THIRD-PARTY-NOTICES.txt 及
web/THIRD-PARTY-NOTICES.txt（附带网页时）。不要将配置、学校资料、证书或私钥
复制到安装包。历史包/已交付 Beta 请保留，不与本次产物互相覆盖。
