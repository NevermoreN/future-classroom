# 学校证书与 HTTPS 入口基础

本目录是 D13 P13-01 的基础组件，编译时显式启用 `school-gateway`。默认桌面程序不启用该依赖或启动学校入口，不增加第十三个 crate。

```console
cargo build -p fc-bootstrap --features school-gateway --bin fc-school-gateway --release --locked
fc-school-gateway init <全新在线状态目录> <全新离线恢复目录> <学校名称> <固定内网IP> <端口>
fc-school-gateway serve <在线状态目录>
fc-school-gateway renew-candidate <在线状态目录> <全新候选状态目录>
```

每条命令从**标准输入读取一行密码**，要求 16～4096 字节。部署工具应从独立的秘密存储传入；不要把密码放在参数、命令历史、项目文件或日志中。当前为命令行基础，不提供交互隐藏输入、秘密存储接线或无人值守服务安装器。

`init` 创建学校独立标识、RSA 2048/SHA-256 根证书（10 年）、中间证书（3 年）和服务证书（90 天）。仅接受明确的 RFC1918 IPv4 或 IPv6 ULA 发布地址；证书包含该 IP SAN，仅用于 Server Authentication。两个目录都必须不存在、父目录必须存在，恢复目录必须在在线状态目录之外；重复执行不会覆盖学校身份。失败时可能保留受保护的部分目录，需管理员确认后处理，程序不自动删除已有状态。

所有私钥均以口令加密的 PKCS#8 保存。Unix 目录/文件权限为 0700/0600。Windows 在线中间和服务私钥另由现有 CurrentUser DPAPI 保护，ACL 仅当前身份、SYSTEM 与管理员：**初始化、续签、运行必须使用同一 Windows 身份**。未来部署为服务时应在对应服务身份下准备状态，不能先用个人账号生成再直接交给其他服务身份。当前组件不是已经安装好的 Windows 服务。

离线目录仅含可迁移的加密根私钥、公开根证书和说明；完成备份确认后移到学校管理员的离线安全介质，与密码分开保管，禁止留在在线服务旁。在线目录不含根私钥。尚未提供完整恢复向导或中间 CA 续签命令，不应把一个目录当作全部学校数据恢复方案。

在线目录提供公开的 `root.cer`、`school-root.mobileconfig`、`root-sha256.txt` 和 `FIRST-USE.txt`。管理员通过已有受信任渠道交付并线下核对指纹；手机仍需完成系统信任，iPhone 可能另需启用完整信任。不能把尚未受信任的 HTTPS 下载页作为唯一首次来源，不能提示忽略证书警告登录。当前未开启任何 HTTP 引导端口；生成描述文件不代表 Android/iPhone 已实际验证。

`serve` 加载时实际校验根链、当前有效期、发布 IP 和服务证书/私钥匹配，绑定明确的发布 IP/端口，提供以下只读 HTTPS 路径：

- `/pwa/`：明确标注基础组件状态的页面。
- `/pwa/api/v1/rooms`：学校标识、名称、空教室列表，明确 `enrollmentEnabled=false`、`relayEnabled=false`。
- `/pwa/root.cer`：公开根证书下载，供已完成信任后的辅助获取。

入口使用 4 个固定工作线程、16 个等待连接、8 KiB 请求头上限和自连接接受开始的 5 秒握手/请求头绝对预算，排队时间计入；队列满立即关闭。每连接仅处理一个 GET，请求必须匹配发布 Host，不接收 GET 正文，不转发任意 URL，不写业务状态，也不记录请求头、正文或凭据。证书过期或校验失败停止启动，无 HTTP 降级。独立进程前台运行，结束该进程停止入口，不操作课堂桌面或音频。

`renew-candidate` 使用在线中间 CA 在新目录生成叶证书并再次校验，保留原学校 ID、根证书和原在线目录不变。中间有效期不足 90 天时拒绝，需管理员先续签中间 CA。**当前没有自动续期调度、原子激活、握手回读或失败回滚管理器**。候选生成成功不代表正在监听新证书；管理员须明确停服、备份并提升候选状态目录，使用同一身份重新启动并验证客户端握手。尚未将此手工流程当作完整 P13-01 验收通过。

当前不包含教室登记/CSR 发证、双向 TLS 设备身份、真实教室目录、教师请求中转、学校 PWA 选班界面、安装器或服务身份配置。不能把空目录入口用作已完成的学校产品，也不会自动修改当前教室监听、证书、账号、防火墙或系统信任。

必要的宿主测试会创建随机临时学校，验证实际 TLS 握手和目录、密码错误拒绝、IP SAN 不符拒绝、离线根隔离与候选续签保留身份，结束后删除自己的临时目录。调试构建使用生产 scrypt 参数，运行较慢；不应为缩短测试降低实际私钥保护参数。
